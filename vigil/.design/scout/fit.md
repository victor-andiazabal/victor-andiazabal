# Fit sheet: VIGIL redesign
- Site type: functional app (offline PWA) on crew tablets/phones; job = daily 2-3 min self-assessment, glanceable status, guidance on what to do, delayed report to the flight surgeon.
- Product nouns: crew member, mission day, vital sign, baseline band, alert (Nominal/Watch/Act now), checklist, check-in, reaction test, body system, light-time delay, downlink report, patch, routine timeline.
- Feel: precise and technical (mission-control instrument clarity), calm intensity; dark default + designed light theme.
- Change: everything visual (layout, nav, dashboard, check-in flow) + NEW first-run tutorial; keep all features, data, rules, sources.
- Keep: React/TS structure, store, rules engine, CSS-var theming approach, body map SVG logic, comm link logic.
- Constraints: big touch targets (microgravity, possibly gloves), few taps, status readable at arm's length, colour never the only signal.
